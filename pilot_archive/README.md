# Pilot Study Archive (Assignment 3 Provenance)

This directory contains the archival artifacts from the 12-item pilot evaluation conducted during Assignment 3 (October 2026), preserved in compliance with Rule 5 (Untouched Test Set):

1. `nlp_pilot_dataset_ground_truth.csv`: 12 pilot items (6 stable, 6 time-sensitive) with reference ground-truth answers and citations.
2. `llm_model_answers.csv`: 36 collected responses across GPT-6, Claude Haiku 4.5, and Gemini 3.8 Flash.
3. `llm_answer_evaluation.py`: Pilot validation and metric calculation script.
4. `screenshots/`: 36 original interface screenshots documenting web browsing disabled and raw outputs.

All pilot materials were finalized prior to freezing the 90-item benchmark (`nlp_benchmark_ground_truth_90.csv`), ensuring zero data contamination.
